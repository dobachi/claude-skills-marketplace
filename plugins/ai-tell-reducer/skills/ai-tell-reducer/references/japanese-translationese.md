# 日本語のAIっぽさ：英語発想の言い回し（翻訳調）

日本語で書かれているのに、英語で考えた文を一語ずつ置き換えたように読める文がある。モデルの学習データは英語が多く、日本語で出力しても英語の構文・慣用句・語の選び方が残りやすい。読み手は「意味はわかるが、日本人はこう書かない」と感じ、その違和感がAIっぽさとして伝わる。

このファイルは、その「英語っぽさ」を見つけて日本語として自然な形に直すための目録である。`japanese-patterns.md` の 8（英語直訳的な言い回し・比喩）を広げたもので、構文・慣用句・語の選び方まで扱う。

各項目は「症状 → なぜ不自然か → 直し方」。Before/After は要点を示すためのもので、**元文にない事実・数字・固有名詞は足さない**（SKILL.md のガードレール）。常体／敬体は元文に合わせる。

## 判定のしかた

回数ではなく、次の二つで判断する。

- **逆翻訳テスト**：その文を英語に戻すと、語順も語も一対一で英語の定型句になるか。なるなら、英語で考えた文を置き換えただけの可能性が高い。（例：「このデータは私たちに多くのことを教えてくれる」→ "This data tells us a lot." がそのまま戻る）
- **書き下ろしテスト**：日本語で最初から考えた書き手が、この内容を書くならどう書くか。その形と違い、しかも日本語の形のほうが短いか明確なら直す。

残すもの：

- **定着した表現**。「氷山の一角」「車輪の再発明」「ボトルネック」「レイテンシ」のように、日本語話者が説明なしで理解し、実際に使っている語や言い回しは翻訳由来でも残す。判断に迷ったら、その分野の日本語の文書で普通に使われているかを基準にする。
- **術語・固有の概念**。分野で決まった訳語や、英語のまま使うのが通例の用語（API名、規格名、論文中の定義語）は変えない。
- **引用・翻訳文**。原文への忠実さが求められる訳文は、このスキルではなく `faithful-translation` の領分。訳文を自然にしたいと頼まれた場合も、意味の幅を変えない範囲にとどめる。
- **著者が意図して使っている英語由来の語**。社内で定着した言い方や、著者の口癖は手を付けない。

## 1. 無生物主語と他動詞

**症状**：モノや出来事が主語になり、人に働きかける。「このデータは私たちに〜を教えてくれる」「この経験が彼を成長させた」「新機能はユーザーが〜することを可能にする」「調査はXが重要であることを示している」。
**なぜ不自然か**：英語は無生物主語＋他動詞が普通だが、日本語は「（人が）〜からわかる」「〜で〜できる」のように、人を主語にするか主語を立てないのが普通。直訳すると擬人化したように読める。
**直し方**：無生物は「〜から」「〜で」「〜によって」の副詞句に下げ、述語を自動詞や「わかる」「できる」にする。

Before：このデータは、利用者の多くが夜間にアクセスしていることを私たちに教えてくれる。
After：このデータから、利用者の多くが夜間にアクセスしていることがわかる。

Before：新機能は、ユーザーが設定を一括で変更することを可能にする。
After：新機能で、設定を一括で変更できる。

※「調査は〜を示している」は論文で定着しており、根拠の所在を明示する役目もある。報告書・論文では残してよい。気になるなら「調査では〜だった」と書く。

## 2. 代名詞の出しすぎ

**症状**：「それは〜」「それらは〜」「私たちは〜」「あなたの〜」「彼らは〜」が文ごとに出る。製品紹介で「あなたのチーム」「あなたのビジネス」。
**なぜ不自然か**：英語は主語と所有格を省けないが、日本語は文脈でわかる主語や所有者を書かない。書くと、指す対象を強調しているように読め、文がくどくなる。「あなた」は日本語では相手を名指す強い語で、文書で読み手を呼ぶ語として使うことはまずない。
**直し方**：文脈でわかる主語・所有者は消す。指示語が要るなら「これ」「この方式」のように具体化する。読み手への呼びかけは「読者」「利用者」にするか、主語を立てない。

Before：それは私たちのチームにとって大きな課題であり、私たちはそれを解決する必要がある。
After：チームにとって大きな課題で、解決しなければならない。

Before：このツールはあなたのチームの生産性を高めます。
After：チームの作業が速くなります。〔何がどう速くなるかが元文にあれば、それを書く〕

## 3. 「持つ」「与える」「取る」「作る」の直訳

**症状**：「大きな影響を持つ」（have an impact）「ポジティブな影響を与える」（have a positive effect）「アクションを取る」「行動を起こす」（take action）「違いを生む」（make a difference）「決定を下す／意思決定を行う」（make a decision）「〜を見てみる」（take a look）「〜に焦点を当てる」（focus on）。
**なぜ不自然か**：英語は「軽い動詞＋名詞」で動作を表すが、日本語は動詞や形容詞一語で言える。名詞を経由すると文が長く、硬くなる。
**直し方**：動詞・形容詞に戻す。

| 直訳調 | 自然な形 |
|---|---|
| 大きな影響を持つ | 影響が大きい／大きく左右する |
| 良い影響を与える | 良くする／役に立つ |
| 対策を取る／アクションを取る | 手を打つ／対処する |
| 違いを生む | 差が出る／結果が変わる |
| 意思決定を行う | 決める |
| 〜を見てみましょう | 〜を見る／〜は次のとおり |
| 〜に焦点を当てる | 〜を中心に扱う／〜を取り上げる |
| 重要な役割を果たす | 〜に欠かせない／〜を担う（役割の中身を書けるならそれを書く） |

Before：この方針は、プロジェクトの成功に大きな影響を持つ重要な役割を果たす。
After：プロジェクトの成否は、この方針で大きく変わる。

## 4. 英語の慣用句の直訳

**症状**：英語の慣用句をそのまま日本語に置き換える。

| 直訳調 | 元の英語 | 自然な形の例 |
|---|---|---|
| 一日の終わりに | at the end of the day | 結局のところ／最終的には |
| 同じページにいる | on the same page | 認識が揃っている |
| 部屋の中の象 | the elephant in the room | 皆が気づいているのに触れない問題 |
| 低く垂れた果実 | low-hanging fruit | すぐ取れる成果／手を付けやすいところ |
| 針を動かす | move the needle | 目に見える効果がある |
| 点と点をつなぐ | connect the dots | 関係に気づく／ばらばらの情報をつなげて考える |
| 〜に光を当てる | shed light on | 〜を明らかにする／〜を取り上げる |
| テーブルに着く／テーブルに載せる | come to / put on the table | 交渉に応じる／議題にする |
| 〜の中心にある | at the heart of | 〜の要だ／〜の根本にある |
| 〜を当然のことと思う | take for granted | 〜をあてにする／疑わない |
| 〜を真剣に受け止める | take seriously | 〜を重く見る |
| 大きな絵 | the big picture | 全体像 |
| ゲームチェンジャー | game changer | 状況を一変させるもの（何がどう変わるかを書く） |
| 〜する価値がある | worth -ing | 〜してよい／〜するとよい（価値の中身を書けるならそれを書く） |
| 〜は意味をなす | make sense | 筋が通る／理にかなう |
| 〜に終わる | end up | 結局〜になる |

**なぜ不自然か**：日本語話者はこの言い方をしないか、知っていても英語由来の気取った表現として受け取る。意味が伝わっても、文が浮く。
**直し方**：表の右列のように字義どおりに言い直す。比喩が要るなら日本語の慣用句を探すのではなく、まず比喩なしで書けるかを考える（借り物の比喩は `expression-and-stance.md` の E6）。日本語のことわざや古風な言い回しに置き換えるのは過剰修正。

Before：一日の終わりに、私たちが同じページにいることが最も重要だ。
After：最終的には、関係者の認識が揃っていることが何より大事だ。

## 5. 決まり文句の直訳（あいさつ・相づち・締め）

**症状**：「素晴らしい質問ですね」（Great question!）「お役に立てれば幸いです」（I hope this helps）「何かあれば遠慮なく聞いてください」（Feel free to ask）「楽しんでください」（Enjoy!）「幸運を祈ります」（Good luck）「ハッピーコーディング」「〜へようこそ」（Welcome to）「あなたは一人ではありません」（You're not alone）。
**なぜ不自然か**：英語の会話の定型を日本語に移したもので、日本語の文書や会話ではこの位置にこの言葉を置かない。チャットAIの出力として特に目立つ。
**直し方**：基本は削る。相手に何かを頼む・促す必要があるなら、日本語の場面に合う定型（「ご不明な点はお問い合わせください」「ご確認をお願いします」）にする。

Before：素晴らしい質問ですね！以下で説明します。……お役に立てれば幸いです。ハッピーコーディング！
After：〔前後の定型を削り、本題だけにする〕

## 6. 構文の直訳

**症状**：
- 「〜することは〜である」「〜することが重要だ」（It is important to …）
- 「〜するために、〜する」が連続する（in order to）
- 「〜することによって」（by -ing）
- 「もし〜ならば」（if）を、条件がはっきりしている場面でも付ける
- 「〜すればするほど」は自然だが、「より〜になればなるほど、より〜になる」（the more …, the more …）と「より」を重ねる
- 「〜だけでなく、〜もまた」（not only … but also）の多用
- 「〜するのに十分な」（enough to）「あまりに〜なので〜できない」（too … to）
- 「〜であることが判明した」（it turned out that）「〜ということが言える」（it can be said that）

**なぜ不自然か**：英語の文型を語順ごと移している。日本語ではもっと短い形がある。
**直し方**：

| 直訳調 | 自然な形 |
|---|---|
| 定期的にバックアップを取ることが重要です | バックアップは定期的に取ってください／定期的に取る必要がある |
| 〜することによって、〜できる | 〜すれば〜できる／〜で〜できる |
| もし設定が正しければ、起動する | 設定が正しければ起動する |
| より多く使えば使うほど、より速くなる | 使うほど速くなる |
| 〜であることが判明した | 〜だった／〜とわかった |
| 〜ということが言える | 〜だ／〜といえる |
| 処理するのに十分な容量がある | 処理できるだけの容量がある |

Before：もしデータ量が増加した場合には、処理を分割することによって、遅延を回避することが重要です。
After：データ量が増えたら、処理を分ければ遅延を避けられます。

## 7. 「〜の一つ」「一つの〜」と数・冠詞の直訳

**症状**：「最も重要な要因の一つ」（one of the most）「一つの解決策として」（a solution）「ある種の〜」（a kind of）「多くの〜たち」（複数形の訳出）「データたち」「ユーザーたち」。
**なぜ不自然か**：英語は数（単数・複数・冠詞）を必ず示すが、日本語は示さないのが普通。訳出すると冗長で、「一つの」が意味のない重みを帯びる。「最も〜の一つ」は「最も」と「一つ」が日本語では噛み合わない。
**直し方**：数が論点でなければ消す。「最も〜の一つ」は「主な要因の一つ」「大きな要因だ」に。

Before：これは最も重要な要因の一つであり、一つの解決策として、ユーザーたちに通知を送ることが考えられる。
After：これは大きな要因だ。対策としては、利用者への通知が考えられる。

## 8. 長い連体修飾と後置の補足

**症状**：関係詞節を名詞の前に積み上げて、主語が出るまでが長い（「〜が〜する際に〜となる〜を持つ〜であるところのX」）。または逆に、英語の後置修飾をまねて、名詞の後ろに「、これは〜」「、それにより〜」「〜であり、それが〜」と補足を継ぎ足す（, which … / , allowing …）。
**なぜ不自然か**：日本語は修飾が前に付くので、長い関係詞節を前に積むと文頭で読み手が迷う。後ろに継ぎ足すと、主節がどこで終わったのかが曖昧になる。
**直し方**：文を分ける。修飾の一部を独立した文にするか、述語の側に移す。

Before：複数の組織が保有するデータを相互に参照する際に必要となる認証の仕組みを提供する基盤であるところのコネクタは、〜。
After：コネクタは、組織をまたいでデータを参照するための認証の仕組みを提供する。〜。

Before：設定ファイルを読み込み、これはキャッシュされ、それにより二回目以降の起動が速くなる。
After：設定ファイルは読み込んだあとキャッシュされるので、二回目以降の起動は速い。

## 9. 前置詞の直訳

**症状**：「〜において」（in）「〜に関して」（about / regarding）「〜に対して」（for / to / against）「〜の観点から」（in terms of）「〜を通じて」（through）「〜に基づいて」（based on）が、一文に何度も出る。
**なぜ不自然か**：英語の前置詞を一つずつ訳すと、助詞一つで足りるところが複合辞になり、硬く長くなる。
**直し方**：「で」「の」「を」「について」など短い助詞で足りるならそれにする。複合辞は一文に一つまでを目安に、それ以上あれば文を組み直す。

Before：本システムにおいて、性能に関して、ユーザーに対してアンケートを通じて調査を行った。
After：本システムの性能について、利用者にアンケートで聞いた。

## 10. 副詞の直訳

**症状**：「実際に」（actually）「本当に」（really）「文字通り」（literally）「基本的に」（basically）「単に」（simply / just）「明確に」（clearly）「間違いなく」（definitely）「非常に」（very）が、意味を足さずに付く。
**なぜ不自然か**：英語の会話で調子を取るための副詞をそのまま訳している。日本語では意味のない強調や留保に読め、文が軽くなる。
**直し方**：消して意味が変わらなければ消す。「実際に計測した」のように、推測と対比して実測を示すなど意味がある場合は残す。

Before：これは実際に非常に便利な機能で、基本的には単に設定を有効にするだけで、明確に効果が出ます。
After：設定を有効にするだけで効果が出る。〔「便利」の中身が元文にあればそれを書く〕

## 11. 未消化のカタカナ語

**症状**：日本語で普通に言える内容を、英語をカタカナにして書く。「インサイトを得る」「アラインする」「コミットする」（約束する意味で）「エンゲージメントを高める」「ナラティブ」「レバレッジする」「ソリューションを提供する」「プライオリティ」「アサインする」「リーチする」「エンパワーする」「イネーブルする」。
**なぜ不自然か**：読み手が英語を思い浮かべないと意味が取れず、しかも意味の幅が曖昧になる。ビジネス文書の決まり文句として、中身のなさを隠す働きもする。
**直し方**：日本語で言い直す。言い直せない固有の意味があるなら残し、初出で短く説明する。

| カタカナ | 言い換えの例 |
|---|---|
| インサイトを得る | 〜がわかる／手がかりを得る |
| アラインする | 認識を揃える／方針を合わせる |
| ソリューションを提供する | 〜を解決する（何を解決するか書く） |
| レバレッジする | 生かす／使う |
| プライオリティが高い | 優先度が高い／先にやる |
| エンパワーする | 権限を渡す／できるようにする |

※職場で定着していて読み手も同じ語を使う場合（「アサイン」「レビュー」「リリース」など）は残す。判断基準は SKILL.md の「Preserve register and voice」と同じで、読み手と文書の慣習に合わせる。

## 12. 英語の約物（コロン、ダッシュ、引用符）

**症状**：地の文でコロン「：」の後に結論を置く（「答えはシンプル：〜」）。全角ダッシュ「——」で挿入句をはさむ。英語の引用符 “ ” や ' ' を使う。セミコロン「；」でつなぐ。
**なぜ不自然か**：日本語の地の文ではこれらの約物の使い方が定まっておらず、英語の文の組み立てが透けて見える。とくに「——」は英語の em dash の癖がそのまま出たもの。
**直し方**：コロンは「〜は〜だ」と文にする。ダッシュの挿入句は括弧か別の文にする。引用符は「」、引用の中の引用は『』。セミコロンは句点で文を分ける。見出し・表・箇条書きのラベルとしてのコロンは使ってよい。

Before：理由はシンプル：標準が揃っていない——少なくとも現時点では——からだ。
After：理由は、少なくとも現時点では標準が揃っていないことにある。

## 過剰修正に注意

- **和語・古語への置き換えすぎ**：定着したカタカナ語や漢語まで和語に開くと、かえって読みにくい。「レイテンシ」を「待ち時間の遅れ」にしない。
- **ことわざ・慣用句の差し込み**：英語の慣用句を消した穴に、日本語のことわざ（「急がば回れ」など）を入れない。新しい飾りが増えるだけ。
- **主語の消しすぎ**：誰が何をするかが論点の文（責任分担、手順の実行者）で主語を消すと、意味が落ちる。消すのは文脈で明らかな主語だけ。
- **文体の破壊**：直訳調を直すついでに、常体と敬体を混ぜたり、口語にしたりしない。
- **術語の言い換え**：分野で定まった訳語や英語のまま使う用語を、自然さのために言い換えない。
