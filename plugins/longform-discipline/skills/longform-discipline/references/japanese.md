# 日本語の長文で効く規則

長い日本語文書は、英語にはない形で崩れる。文体が途中で変わり、同じ語が二通りに書かれ、一文が伸びて
係り受けが壊れる。いずれも**機械的に検出できる**ので、`drift_scan.py` が拾い、ここがその根拠を持つ。

一次情報は二つ。文化審議会建議「公用文作成の考え方」（2022年、以下「建議」）と、
JTF日本語標準スタイルガイド（翻訳用）第4.0版。どちらも公文書・実務文書の基準であり、小説やエッセイ
には必ずしも当てはまらない。**この文書のジャンルに合うかを判断してから適用すること。**

## 1. 文体を混ぜない

長文で最も起きやすく、最も目立つ崩れ。章ごとに別セッションで書けば、ほぼ確実に起きる。

> 「一つの文書内では、文末表現に敬体と常体とを混合して用いない。どちらか一方のみで統一する。」
> — 建議 https://www.bunka.go.jp/seisaku/bunkashingikai/kokugo/hokoku/pdf/93651301_01.pdf

建議は例外も明示している（引用、従属節、箇条書きに別の文末表現が現れるのは問題ない）。
`drift_scan.py` は箇条書き行と引用行を除いて数えるが、判断は人がする。

> 「本文の文体は、敬体（ですます調）あるいは常体（である調）のどちらかで統一します。敬体と常体を
> 混在させないようにします。」
> — JTF日本語標準スタイルガイド 第4.0版 https://www.jtf.jp/pdf/jtf_style_guide.pdf

**運用**: 文体はスパインファイルの「style contract」で**起草前に**決める。後から決めると全文書き直しになる。

## 2. 一文を伸ばさない

一文の長さは、係り受けの壊れやすさの代理指標として使える。

> 「一文が長くなると、その構造は複雑になりやすい。前の語句と後の語句との係り受けや主語と述語の関係が
> 乱れるなど、読みにくくなりがちである。」

> 「適当な長さは一概に決められないが、50～60字ほどになってきたら読みにくくなっていないか意識するとよい。」
> — 建議

建議自身が「一概に決められない」と留保していることに注意。**60字は禁止線ではなく点検線**である。
`drift_scan.py` は 60字で `warn`、100字で `high` を出すが、どちらも「読み直せ」の合図であって、
自動的な誤りではない。

建議は分割の手段も具体的に挙げている——句点や接続詞を使う、長い修飾語・修飾節を別の文に移す。

## 3. 係り受けは近づける

> 「主語と述語、修飾語・修飾節と被修飾語、目的語と述語など、係り受けの関係がある語は、近くに置くと
> 関係が分かりやすい。同様に、指示語を用いるときにも、指示される内容の近くに置く。」
> — 建議

長文特有の問題として、**指示語が章をまたぐ**ことがある。「この方式」「先述の課題」が、数千字前の
記述を指していて、読者がもう覚えていない。章の冒頭に現れる指示語は、原則として固有名に開く。

語順の基本形も建議が示している:

> 「日本語では、「いつ」「どこで」「誰が」「何を」「どうした」という順で書かれることが多い。
> この語順を守っておけば、おおむね読み取りやすい文になる。」

## 4. 表記を揺らさない

長文では、同じ語が章ごとに別の表記になる。AIと分割して書けば、ほぼ必ず起きる。

> 「従来の公用文の書き表し方を守り表記の揺れを防ぐとともに、誤読されたり複数の意味に解釈されたり
> するおそれのない書き方をするよう努める。」
> — 建議

よく揺れる軸:

| 軸 | 例 |
|---|---|
| カタカナ長音 | サーバー / サーバ、ユーザー / ユーザ、コンピューター / コンピュータ |
| 送り仮名 | 行う / 行なう、表す / 表わす、申し込み / 申込み / 申込 |
| 漢字/かな | 事 / こと、時 / とき、出来る / できる、下さい / ください |
| 数字・単位 | 10 / １０、5% / 5％、2026年 / 令和8年 |
| 訳語 | データ空間 / データスペース、機械学習 / ML |

**運用**: 揺れる語はスパインの glossary に「canonical」と「never write」で固定する。
`drift_scan.py --spine` はその表を検査に使う。glossary に無い揺れも、既知パターンから推定して報告する。

## 5. 重言・二重否定を避ける

> 「意味が重複する表現（「重言」「重ね言葉」などとも。）は、むやみに用いないようにする。
> 例）諸先生方 → 諸先生、先生方　各都道府県ごとに → 各都道府県で、都道府県ごとに
> 第１日目 → 第１日、１日目　約20名くらい → 約20名、20名くらい
> 違和感を感じる → 違和感を覚える、違和感がある」
> — 建議

> 「二重否定やそれに類する表現を用いると、否定しているのか肯定しているのか分かりにくくなることがある。
> 強調したいことを効果的に伝えようとするような場合を除き、なるべく避ける。
> 例）…しないわけではない → …することもある」
> — 建議

どちらも建議が「むやみに」「なるべく」と留保している点は残す。強調のための意図的な二重否定はある。

## 6. 長文で追加される、日本語固有の点検

一次情報にある規則ではなく、上の規則を長文に当てはめたときに出てくる実務上の観点。

- **章をまたぐ敬語の揺れ**: 「いたします」「させていただく」の濃度が章ごとに変わる。文体契約に
  敬語のレベルも書いておく。
- **接続詞の癖の偏り**: AIは「また」「さらに」「一方で」を過剰に使う。章ごとに頻度を見ると、
  同じ接続詞で始まる段落が並ぶ。`repeated-opener` が拾う。
- **箇条書きの句点**: 章によって「。」が付いたり付かなかったりする。文体契約で決める。
- **数字の全角/半角**: 章ごとに混ざる。文体契約で決める。
- **引用の表記**: 「」と『』と "" が混在する。文体契約で決める。

## 適用しない場面

これらは公文書・実務文書の基準である。以下では**当てはめない**か、緩めて使う:

- 小説・エッセイ・詩 — 一文の長さも文体の揺れも技法でありうる
- 会話・インタビューの書き起こし — 話者の言葉を直す対象ではない
- 引用文 — 原文のまま。`faithful-translation` の領分
- 既存の社内スタイルガイドがある場合 — そちらが優先。スパインの style contract にそう書く
