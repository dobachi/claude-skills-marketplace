# Platform Rules

LinkedIn mechanics first, then the conversion table for other platforms. Each rule is tagged
with how well it is established, because most published LinkedIn "algorithm" guidance comes
from tool vendors with an interest in the answer.

確度: **[確]** プラットフォーム仕様・報道など確かなもの / **[傾]** 複数ベンダーの分析が一致する傾向 /
**[説]** 出所が一社・一データセットに依存する主張。**[説] は運用の目安にはするが、断定して書かない。**

## LinkedIn

| 項目 | 値 | 確度 |
|---|---|---|
| 本文の上限 | 3,000 文字 | [確] |
| "See more" で切れる位置 | モバイル 約140字 / デスクトップ 約200〜210字 | [確] |
| 実務的な長さ | 800〜1,500字程度（内容がある投稿） | [傾] |
| ハッシュタグ | 3〜5個、末尾。発見機能としての価値は低下 | [傾] |
| ハッシュタグの入れすぎ | 6個以上でスパム扱い・到達減という主張 | [説] |
| 本文中の外部リンク | 到達が下がる傾向（130万投稿の分析で中央値 -18.8%）。1stコメントに置く運用が定番 | [説]（傾向としては[傾]） |
| 画像・カルーセル | 複数画像・PDFカルーセルはテキスト単体より反応が高いとされる | [傾] |
| 個人 vs 会社ページ | 個人アカウントの方が届きやすい。倍率（8x/14x など）は出所により大きく異なる | [傾]（倍率は[説]） |
| engagement bait | 「1と答えて」等はスパム的パターンとして扱われる | [傾] |

**書き手として守るのはこれだけでよい**: 冒頭140字に結論、リンクは1stコメント（または末尾）、
ハッシュタグ3〜5、engagement bait なし、具体を1つ。数字の倍率を根拠に文面を作らない。

### 投稿の物理

- 改行は段落単位。1文ごとの改行連打（broetry）はしない。
- 箇条書きは3〜5項目、行頭は「・」か「-」。絵文字を行頭記号にしない。
- 画像には alt テキストを付ける（アクセシビリティ、かつ内容の説明になる）。
- カルーセル（PDF）は、順に読ませたい論点が3枚以上あるときだけ。1枚で足りるなら画像1枚。
- 1stコメントのリンクには一行の説明を添える。裸のURLだけは置かない。

## 他プラットフォームへの変換

同じ素材から出すときの差分。LinkedIn 版を原本として、次の表で変換する。

| | LinkedIn | X (Twitter) | Facebook | note・ブログ告知 |
|---|---|---|---|---|
| 長さ | 800〜1,500字 | 140字前後（1投稿）／スレッドで分割 | 300〜800字 | 見出し＋本文（長文可） |
| 硬さ | 中間（既定） | 一段カジュアル、結論だけ | 中間〜カジュアル、身内寄り | 中間、説明的 |
| 冒頭 | 140字に結論 | 1文目が全て。前置き禁止 | 1〜2文で結論 | 見出しで結論 |
| リンク | 1stコメント推奨 | 本文末尾でよい | 本文でよい | 本文でよい |
| ハッシュタグ | 3〜5、末尾 | 0〜2、本文に溶かす | 0〜2 | 記事タグとして別枠 |
| 絵文字 | 0〜2 | 0〜1 | 0〜2 | 0〜1 |
| 併記 | 併記または別投稿 | 言語ごとに別投稿（字数的に併記不可） | 併記可 | 記事内で節を分ける |
| 固有の注意 | 準公式に読まれる | 引用と誤読されやすい。断定の強さに注意 | 実名の知人に届く | 検索から来る読者を想定 |

X に落とすときは「LinkedIn の本文を縮める」のではなく、**フックだけを取り出して独立した1文に
する**。縮約した長文は必ず不自然になる。

## 投稿タイミング

平日の業務時間帯（朝〜午前）が一般に良いとされる [説] が、フォロワーの職種と地域で変わるため、
**時間帯を根拠に文面を変えない**。海外読者を含む場合は、どのタイムゾーンに合わせるかだけ確認する。
