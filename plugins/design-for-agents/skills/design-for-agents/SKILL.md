# design-for-agents — ルータ

**このスキルは中身を持たない。** デザインの判断は本リポジトリの
`INDEX.md` 以下にあり、このファイルの役目はそこへ渡すことだけである。

## 手順

1. **`../../INDEX.md` を読む。** これがルーティング表であり、常時読む唯一の入口
2. **INDEX の第0節「実行手順」に従う。** 媒体 → モード → ジャンル →
   要素 → 制約 → 決め打ち値と禁止事項 の順に、該当した行のファイルだけを開く
3. **生成後、読んだ全ファイルの `done_when` を1つずつ確認する**
4. **`needs_human` と INDEX 第8節の項目を、名指しでユーザに返す**

## してはならないこと

- **記憶からデザインの助言をする。** 一般論で答えず、必ず INDEX を引く。
  本リポジトリの価値は知識の新しさではなく、引けば一意に決まることにある
- **リポジトリ全体を読み込む。** INDEX が指した行のファイルだけを開く
- **状態が `未作成` の行を推測で埋める。** その旨をユーザに伝え、
  本リポジトリを根拠に使わない
- **`.pptx` を自分で書く。** python-pptx を直接書くと、白紙レイアウトに
  テキストボックスを置く形になり、スライドマスターが何も支配しなくなる。
  生成・抽出は `pptx-build` に渡す
- **判定できないことを、できたことにする。** 美しさ、ブランド適合、
  レンダリング結果の見た目はテキストでは判定できない

## ジャンルの判定で迷ったとき

推測しない。ユーザに聞く。

> この資料を見た相手に、決めてほしいのか／分かってほしいのか／興味を持ってほしいのか。

## 衝突したとき

INDEX 第7節の順序に従う。**MUST > ユーザ／組織の明示指定 > SHOULD > HOUSE。**
`HOUSE` はユーザ指定やコーポレートテンプレートがあれば即座に上書きされる。
それは失敗ではない。
