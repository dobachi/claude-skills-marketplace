# 構図は内容の形から選ぶ

## 型を選ぶことが、設計の判断そのものである

置き方を先に決めて内容を流し込むと、レイアウトが内容の代わりに主張してしまう。
**等価でない4項目を等幅のカードで並べれば、「この4つは同じ重みだ」という、
内容が支えていない主張になる。** 逆に、順序のある工程を箇条書きにすれば、
順序という情報が消える。

だから条件のほうが型より重要である。下表の右列を満たさない型は使わない。

| 内容の形 | 型 | 使ってよい条件 |
|---|---|---|
| 等価な単位 | カード | 同じ種類のものである。順位でも羅列でもない |
| 実在する順序 | ステップ | 順序または依存が実際にある |
| 1件が他より重い | リード | 主役の面積が大きい。面積が主張になる |
| 2つの軸での位置 | マトリクス | 両軸に名前があり、4象限すべてが何か言う |
| 図とその読み | 非対称分割 | 図が主役で、文章はその読み方である |
| 論の転換 | 一文だけのページ | 章が変わる、または判断を宣言する |

## なぜ HOUSE なのか

型の一覧にも、個数の上限にも外部の根拠は無い。決めないと、生成のたびに
別の置き方が選ばれてスライド間で揺れる。ユーザや組織のテンプレートが別の型を
持っていれば、そちらが優先する。

## 矢印はステップにだけ許される

順序を表さない矢印は置かない（`core-diagram-arrow-one-meaning`）。ステップは
その順序が実在する場合の型なので、ここでだけ矢印が情報を運ぶ。

## 図が横に長いとき

横幅と高さの比が 2 を超える図は、非対称分割に入れると小さくなる。全幅の図として
置き、読み方は図の下に短く添える。
