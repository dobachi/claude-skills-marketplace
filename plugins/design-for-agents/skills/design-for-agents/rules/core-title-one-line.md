# タイトルは1行

## 長さの規律が、大きな文字を可能にする

タイトルと本文の級数差は、そのスライドで最初に働く階層である。差が小さければ、
見出しは「少し大きい文である」としか読まれない。

ところがタイトルが折り返すと、2行を収めるために生成器は級数を1段落とす。
**長いタイトルは、それ自体が級数差を消す。** つまり大きなタイトルを使える条件が
短さであって、順序は逆にできない。先に長さを決めてから級数を上げる。

## 22という数

日本語で 34pt のタイトルが16:9の本文幅に1行で収まる上限が、およそ全角22文字である。
外部の根拠は無い。判型・書体・余白を変えれば動く。動かしたときは、
2行になったスライドが 0 枚であることだけを確かめる。

## 短くできないとき

タイトルが長くなるのは、たいてい1枚に2つのことを言おうとしているからである
（`core-density-one-message`）。文を削るより先に、スライドを割る。
