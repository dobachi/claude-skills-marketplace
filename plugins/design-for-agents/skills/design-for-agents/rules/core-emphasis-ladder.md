# 強調ははしご

## なぜ色が最後なのか

色から入ると、次に強調したいものがもう無くなる。位置と余白による強調は
コストがゼロで、他の強調を消費しない。**色は在庫が1つしかない。**

## はしご

1. **位置** — 先頭に置く、または単独で置く
2. **孤立** — まわりに余白を作る
3. **サイズ** — スケールを1段上げる（2段は上げない）
4. **太さ** — 太字。文ではなく数語に掛ける
5. **アクセント色** — 最後。1スライドに1箇所

## 「1箇所」の数え方

同じ役割の並列要素に、同じ大きさ・太さでアクセント色を当てるのは**反復**であり、
1箇所と数える（2段組の両列見出しなど）。**違う書式でアクセント色が2回出たとき**が
強調の競合であり、それを禁じている。

この数え方は、検出器を pptx-build の出力に当てて分かった。当初の条件は
「アクセント色の文字が2箇所以上」で、反復と競合を区別できていなかった。

## 使わない手段

- **下線** — リンクに見える
- **日本語のイタリック** — 書体が対応せず、傾けただけの字形になる
- **長い文の全角大文字・全大文字** — 読みにくくなる
- **2段の同時使用** — 太字かつ色かつサイズ、は強調ではなく叫びである
