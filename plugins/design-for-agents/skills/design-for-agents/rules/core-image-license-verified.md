# 画像のライセンス

## なぜこれを規則にするのか

**「無料」は「商用資料で使える」を意味しない。** 個人利用に限る素材、
帰属表示が要る素材、再配布を禁じる素材が混ざっている。社外に出る資料で
これを外すと、直すのは資料ではなく関係になる。

生成AIで作った画像も同じである。モデルの利用条件を確認する。

## 確認する項目

| 項目 | 例 |
|---|---|
| 出所 | どのサイトの、どの画像か |
| ライセンス | 商用可か、帰属表示が要るか、改変が許されるか |
| 確認した日 | 条件は変わる |

**画像ごとに確認する。** サイト単位で「ここは自由」と決めない。
同じサイトでも画像ごとに条件が違うことがある。
