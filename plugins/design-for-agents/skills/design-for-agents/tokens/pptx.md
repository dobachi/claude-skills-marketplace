# 決め打ち値（PowerPoint）

**正は [`pptx.tokens.json`](pptx.tokens.json) である。** この表は転記であり、
ここで新しい値を決めない。値を変えるときは JSON を直し、この表を写し直す。

DTCG の `dimension` 型は px と rem しか許さないため、pt と inch の値は
`number` 型で表し、単位は `$description` に書いている。

## 色（`core-color-four-slots`）

| 枠 | 値 | paper とのコントラスト比 | 用途 |
|---|---|---|---|
| paper | `#FFFFFF` | — | 背景。全スライド共通 |
| ink | `#1A1A1A` | 17.4:1 | 見出しと本文 |
| muted | `#6B7280` | 4.83:1 | 第2階層、キャプション、出典行、ページ番号 |
| accent | `#2F5DA8` | 6.46:1 | ヘアラインと、1スライドにつき1箇所の強調 |
| chartGrid | `#E5E7EB` | — | グラフの横目盛線。データを表さないので、読み取りに要るときだけ残す |

暗色デッキ: paper `#111315` / ink `#F2F2F2`（16.63:1）/ muted `#9AA1AC`（7.15:1）。
**1つのデッキで明暗を混ぜない。**

ブランド色は accent に転写する。転写前に 4.5:1 を確認する
（`core-a11y-contrast-body`）。

## グラフの系列色（`core-color-cvd-distinguishable`）

3系列以上を色で区別するときだけ使う。本文には使わない。

`#E69F00` `#56B4E9` `#009E73` `#F0E442` `#0072B2` `#D55E00` `#CC79A7` `#000000`

出典: Okabe & Ito, Color Universal Design（`docs/sources.md` の `okabe-ito`）。

## 型スケール（`core-type-one-scale`、単位 pt）

| 用途 | pt |
|---|---|
| 表紙のデッキタイトル | 40 |
| 表紙の副題・キッカー | 20 |
| 章扉 | 34 |
| 章扉の番号 | 22 |
| スライドタイトル | 30（自動縮小の下限 24） |
| 本文 第1階層 | 18 |
| 本文 第2階層 | 16 |
| 図のキャプション / 注記 | 15 / 14 |
| 表の中 / 表の見出し行 | 15 |
| グラフのラベル | 12 |
| 出典行 / ページ番号 | 11 |
| 大きな数値 / その説明 | 88 / 20 |
| 引用 / 引用の出所 | 28 / 18 |

行間は文字サイズの **1.3倍**、段落間隔は **0.5行**（`core-type-leading`）。
本文に使う書体は `fontFamily.sans` に列挙したサンセリフ（`core-type-sans-projection`）。

18pt は**下限であって目標ではない**（`core-type-body-floor`）。
自動縮小を許すのはタイトルだけである。

## 同系のトーン（`core-color-tonal-ramp`）

`accent` が `#2F5DA8` のときの値。ブランド色に差し替えたら、**同じ明度で作り直す**。
白と混ぜず、HSL で明度だけを指定する。

| 用途 | 値 | 明度 |
|---|---|---|
| 部品の地 | `#F4F6F8` | 0.965 |
| 強調された部品の地 | `#E9ECF1` | 0.93 |
| 部品の縁 | `#E0E4EB` | 0.90 |
| 転換のページの地 | `#0F1B2E` | 0.12 |
| 同系グラフ 第1系列 | `#2F5DA8` | accent そのもの |
| 同系グラフ 第2系列 | `#6E8BB9` | 0.58 |
| 同系グラフ 第3系列 | `#A2B2CD` | 0.72 |
| 同系グラフ 第4系列 | `#CFD6E2` | 0.85 |

隣接する系列の明度差は 0.13 以上あける。同系で分けたグラフは、凡例ではなく
マークの近くに系列名を置く（`core-chart-direct-label`）。
