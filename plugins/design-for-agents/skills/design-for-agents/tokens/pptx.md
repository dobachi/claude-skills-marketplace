# 決め打ち値（PowerPoint）

**正は [`pptx.tokens.json`](pptx.tokens.json) である。** この表は転記であり、
ここで新しい値を決めない。値を変えるときは JSON を直し、この表を写し直す。

DTCG の `dimension` 型は px と rem しか許さないため、pt と inch の値は
`number` 型で表し、単位は `$description` に書いている。

## 色（`core-color-four-slots`）

| 枠 | 値 | paper とのコントラスト比 | 用途 |
|---|---|---|---|
| paper | `#FFFFFF` | — | 背景。全スライド共通 |
| ink | `#1A1A1A` | 17.4:1 | 見出しと本文 |
| muted | `#6B7280` | 4.83:1 | 第2階層、キャプション、出典行、ページ番号 |
| accent | `#2F5DA8` | 6.46:1 | ヘアラインと、1スライドにつき1箇所の強調 |
| chartGrid | `#E5E7EB` | — | グラフの横目盛線。データを表さないので、読み取りに要るときだけ残す |

暗色デッキ: paper `#111315` / ink `#F2F2F2`（16.63:1）/ muted `#9AA1AC`（7.15:1）。
**1つのデッキで明暗を混ぜない。**

ブランド色は accent に転写する。転写前に 4.5:1 を確認する
（`core-a11y-contrast-body`）。

## グラフの系列色（`core-color-cvd-distinguishable`）

3系列以上を色で区別するときだけ使う。本文には使わない。

`#E69F00` `#56B4E9` `#009E73` `#F0E442` `#0072B2` `#D55E00` `#CC79A7` `#000000`

出典: Okabe & Ito, Color Universal Design（`docs/sources.md` の `okabe-ito`）。
