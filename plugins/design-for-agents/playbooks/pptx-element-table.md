# 表のスライド

## 状況

表は、読み手が**値を引く**ためのものである。傾向を見せたいならグラフが正しい。

## 手順

1. **表かグラフかを決める。** 正確な値が要る、読み手が特定のセルを探す、
   1行に複数の指標が要る、のいずれかなら表。そうでなければグラフ
2. **数が2〜3個なら表にしない。** 文の中に書く
3. **列と行を絞る。** 6列 × 8行まで。超えるものは付録に置く
4. **罫線を消す。** 縦罫は引かない。横罫は見出し下と合計行の上だけ
5. **揃える。** 数値は右揃え、文字は左揃え、小数点以下の桁数は列内で統一
6. **単位を見出しに出す。** 各セルに単位を書くと桁が揃わなくなる
7. **強調を1つ置く。** 主張に関わる行だけを太字にし、薄い塗りを敷く
8. **出典行を置く。**

## 決め打ち値

- **上限**: 6列 × 8行
- **表の文字**: 15pt
- **縦罫**: 引かない
- **横罫**: 見出し下に1本、合計行の上に1本
- **行ごとの縞模様**: 使わない

## よくある失敗

- **格子状に罫線を引く。** 目が升目に閉じ込められ、行どうしの比較ができなくなる
- **中央揃えにする。** 桁が揃わず、表でもっとも精度の高い比較（位置による比較）が
  失われる
- **1.5 と 1.50 を混ぜる。** 列内で桁数を揃える
- **付録に置くべき表を本編に置く。** 8行を超えたら、それは参照用である
