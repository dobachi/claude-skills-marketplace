# 情報テスト

## 手順

図を描く前に2つ答える。

1. **この図はどの構造を符号化するか。** 関係／流れの向き／階層／包含／並行／
   時間順序／グルーピング／隣接 のいずれかを名指しする
2. **図形と矢印を消して文言だけ残したら、何が失われるか**

2の答えが「何も失われない」なら、それは装飾である。**箇条書きに衣装を着せたもの**で
あって、図ではない。

## 3つの直し方

| 直し方 | 選ぶとき |
|---|---|
| 図形を消す | 内容が並列な項目の列挙だったとき |
| グラフに置き換える | 内容が量だったとき |
| 構造を実際に符号化して描き直す | 構造はあるが符号化されていなかったとき |

## 図が正当化される内容

3つ以上の要素の非自明な関係、分岐や並行を含む工程、システムの構成と境界、
深さのある階層、2×2 の区分、状態遷移、時間順の相互作用、意味のある集合の重なり。

**どれにも当てはまらないなら、箇条書きか表が正しい。** 図を作らない。
