# 矢印の意味は1つ

## なぜ

1枚の図の中で、ある矢印がデータの流れを、別の矢印が依存関係を表していると、
読み手はどちらの規則で読めばよいか判断できない。
**混在は誤りであって、細かい指摘ではない。**

依存の向きは特に反転しやすい。「A → B」が「A が B を呼ぶ」なのか
「A が B に依存される」なのかは、図を見ても決まらない。凡例に書く。

## 併せて守るもの

- **箱には定義を置く。** ラベルだけでは、読み手はそれが何か分からない。
  箱の中に1行の説明を入れるか、既知の製品名・構成要素名を使う
- **境界でグループ化する。** 配置の境界、信頼境界、所有組織、ネットワーク区画の
  いずれか、意味のある境界だけを枠で囲む
- **辺にラベルを置く。** 経路やプロトコルが主張に関わるときは書く
